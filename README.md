# 🚀 GiorgIT — Soluciones Tecnológicas de Nueva Generación

Sitio web oficial y plataforma showcase de soluciones digitales de **GiorgIT**, destacando nuestra solución de **Ecommerce de Alto Rendimiento**.

Inspirado en la estética minimalista y moderna de recal.dev, adaptado al ecosistema de comercio electrónico sin límites de escala y optimizado para despliegue nativo en **Vercel**.

---

## ✨ Características Principales

- **Hero High-End**:
  - Tipografía editorial con acentos en *Instrument Serif* y estilo moderno sans-serif (*Inter*).
  - Fondo cósmico atmosférico con nubes etéreas generado a medida (100% original, sin derechos de autor de terceros).
  - Botón pill interactivo con insignia circular animada.
- **Showcase Interactivo en Vivo**:
  - **Storefront**: Ficha de producto interactiva con variantes de color, talles y agregado al carrito en tiempo real.
  - **Checkout 1-Click**: Flujo sin fricción con simulación de Mercado Pago, Stripe, transferencia bancaria con descuento y confirmación instantánea.
  - **Métricas & Analytics**: Dashboard en vivo con gráfico de facturación diaria, ticket promedio, tasa de conversión y ventas en tiempo real.
  - **Google Lighthouse 100/100**: Medición de Core Web Vitals en verde (FCP 0.38s, LCP 0.54s, CLS 0.000).
- **Barra de Pruebas y Métricas**:
  - +48% Tasa de Conversión vs tiendas tradicionales.
  - < 0.6s Tiempo de carga promedio.
  - 99.9% Uptime garantizado en el Edge.
  - 0% Comisiones abusivas por venta.
- **Bento Grid de Soluciones**:
  - Checkout ultrarrápido sin redirecciones innecesarias.
  - Búsqueda y filtrado instantáneo en catálogo.
  - WhatsApp Commerce automatizado.
  - SEO Enterprise con microdatos y Schema JSON-LD.
  - Panel de administración y control de inventario.
- **Tabla Comparativa**:
  - GiorgIT vs Shopify vs TiendaNube vs WooCommerce.
- **Calculadora de Ahorro en Comisiones**:
  - Deslizador interactivo para estimar el dinero ahorrado al no pagar porcentaje por transacción.
- **Planes & Paquetes**:
  - Starter Store, Growth Scale y Enterprise Headless.
- **Formulario de Contacto & Botón WhatsApp**:
  - Formulario de cotización con validación interactiva y contacto directo.

## 🛠️ Tecnologías Utilizadas

- **Framework**: Next.js 15 (App Router)
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Iconos**: Lucide React
- **Animaciones**: Framer Motion
- **Hosting / Deploy**: Vercel (100% compatible out-of-the-box)

---

## 🚀 Despliegue en Vercel

1. Ve a https://vercel.com/new
2. Conecta tu cuenta de GitHub y selecciona el repositorio `giorgit`.
3. Vercel detectará automáticamente la configuración de Next.js (Build command: `npm run build`, Output directory: `.next`).
4. Haz clic en **Deploy** y tu sitio estará en línea en menos de un minuto.

---

## 💻 Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar build de producción
npm run start
```
